# CG
Magnificent Seven Stock Tracker
A Streamlit web app that displays the latest available daily prices and historical charts for NVIDIA, Apple, Microsoft, Amazon, Alphabet, Meta, and Tesla.

Prices are checked every five minutes while the app is open. Data comes from Yahoo Finance and may be delayed or unavailable.

Run locally - ".\.venv\Scripts\python.exe -m streamlit run stock_app.py"
Open the URL printed in the terminal. Use Refresh prices to fetch data immediately.

For informational purposes only—not investment advice.
