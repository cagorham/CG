# CG

A simple weather app built with plain HTML, CSS and JavaScript. Data comes from the free [Open-Meteo](https://open-meteo.com/) API, so no API key is needed.

## Features
- Search for a city
- Use your current location
- Current conditions plus a 7-day forecast
- Switch between °C and °F
- Remembers your last location and unit choice

## Run
```sh
python3 -m http.server 8000
```
Open http://localhost:8000.
